controls the user must click, in order. Do not estimate any coordinates — choose from the list.

Return strict JSON and nothing else. No prose, no code fence.

{
  "goal": "short description of the goal",
  "needs_more": false,
  "steps": [
    { "n": 1, "element": 12, "instruction": "Click the File menu" }
  ]

- If the control you need is not in the list, leave that step out rather than guessing a number.

  "needs_more": true.
